What the grader looks for

  • Sets: ∈ vs ⊆ precisely; |P(A)| = 2^|A|; give a reason for every element-chasing step.
  • Proofs: name the technique; for constructions, give the full 5-tuple idea (states, start, accept, δ) and argue why it works; for contradiction, end with an explicit "contradiction".
  • Automata: every DFA state has exactly one arrow per symbol; trace with the full state sequence; in NFA → DFA start from E(q₀) and take the ε-closure after every move; accept = sets containing an NFA accept state.
  • Regex: give one string in and one out as a check.
  • Pumping: never give p a value; s depends on p; handle every split via |xy| ≤ p; write the pumped string and why it is not in L.

Every answer was checked by computer (regexes on all strings up to length 10, automata simulated, pumping proofs over every legal split). This is a practice paper written from the Midterm Review. It is not the real exam.
