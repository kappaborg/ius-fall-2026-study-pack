# Third-party files used by the in-browser Java fallback

- `ecj.jar` — Eclipse Compiler for Java 3.40.0 (org.eclipse.jdt:ecj, Maven Central, SHA-1 5c26f6a20278196f8038a284d885c3796cd7d422). Eclipse Public License 2.0.
- `java17-api.jar` — Java SE 17 API signatures (java.base, java.logging, java.sql, java.desktop, java.xml, java.prefs, java.datatransfer, java.net.http) extracted from an OpenJDK `lib/ct.sym`. GPL-2.0 with the Classpath Exception.
- The JVM itself is CheerpJ (Leaning Technologies), loaded from its CDN under the community licence — Built with CheerpJ.
