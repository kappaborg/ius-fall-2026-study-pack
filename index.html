Textbooks

The sites summarise every textbook chapter by chapter. The books themselves come from their official sources:

  • CS313 · Maheshwari & Smid, Introduction to Theory of Computation — free from the authors; Sipser, Introduction to the Theory of Computation (Cengage)
  • CS105 · Savitch, Absolute Java (Pearson); Carrano & Henry, Data Structures and Abstractions with Java (Pearson)
  • CS498 · Foster, Generative Deep Learning, 2nd ed. (O'Reilly) — the book's code is free on GitHub
  • MATH204 · Epp, Discrete Mathematics with Applications, 5th ed. (Cengage)
  • IE408 · Meredith & Mantel, Project Management: A Managerial Approach (Wiley)

Check the IUS library and the e-campus course pages for copies.

Textbooks are not included. The notes summarise the books, but the book pages themselves are left out. Use your own copy.

Check against the official course pages. The notes are a study aid written from the slides. Exam dates and grading come from the lecturers and e-campus.

Code exercises: open a chapter's ⌨ Exercises tab — Java is compiled online on real OpenJDK (wandbox.org) and, if that service is busy, inside your browser (Built with CheerpJ). Python runs in your browser. Every site also has a ⌨ Code playground.
